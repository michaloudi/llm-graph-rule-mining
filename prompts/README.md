# Prompts

This directory documents the prompt templates used in the MSc experiments.

The prompts are separated by dataset (`twitter` and `movies`) and by experimental setting:

- zero-shot schema prompting
- few-shot schema prompting
- zero-shot graph-instance prompting
- few-shot graph-instance prompting
- Cypher query generation

Placeholders such as `{description}`, `{chunk}`, `{incident_schema}`, and `{consistency_rules}` are populated at runtime by the notebook.

These files are documentation-oriented copies of the prompts used in the experimental notebook.
